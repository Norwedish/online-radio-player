# API

This document grows with M6 (control API) and M11 (public API).

Planned base URLs:

- Admin/control: `/api/*` (session cookie or API key)
- Public: `/api/public/*`
- WebSocket: `/ws`
- OpenAPI: `/api/docs`
- Health: `/api/health`
- Readiness: `/api/ready`

The full endpoint list is in [`PLAN.md`](../PLAN.md) §6.7.
